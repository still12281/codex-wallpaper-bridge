# 网页浏览器试验通道

## 路线与使用

网页可以做。DSH的关键组合是本地目录资源服务、HTML中先注入Wallpaper Engine兼容API，再由浏览器执行作者脚本；字节broker本身不能代替浏览器的目录与脚本环境。本项目新增明确选择的“网页浏览器（试验）”，复用已固定版本的DSH `serve.js`/focus guard及WebWallGL `web-shim.js`，在独立无窗口Chrome/Edge中执行，再通过私有调试管道取得JPEG，沿现有Codex画布链路播放。无需嵌入HTTP网页到官方客户端，也不修改官方CSP。

在导入页选中Web项目，将导入方式设为“网页浏览器（试验）”，可仅保存或导入并应用。已有Web原版兼容记录不会迁移；同一逻辑壁纸可分别保留WE与Chromium版本，删除/轮播仍按现有逻辑分组。自动路由继续Scene优先GPU（WebGL）、Web优先WE、图片/视频直接播放。浏览器网页输出有JPEG采集、转发、解码成本，不承诺和WebGL直绘同等帧率。

## 范围与生命周期

- 需要本机已安装Chrome或Edge；只使用专用目录，不访问个人浏览器profile。最多两个固定profile槽用于当前源与候选，缓存有界，不生成无限临时profile。
- 支持项目内HTML、相对JS/CSS/图片/媒体资源以及部分WE兼容API；作者属性在首次加载和恢复重载时seed。此轮没有系统音频、鼠标转发、iCUE、全WE API或外网内容支持。worker的HTTP资源请求被禁用，WebRTC不支持。
- 源暂停立即记录状态并串行关闭专用浏览器，保留最后JPEG；恢复重新加载作者网页，内部状态重置，帧序号继续递增。快速暂停/恢复通过revision丢弃旧任务。没有采用无法可靠恢复rAF的冻结/解冻路线。
- 静态网页停止提交新帧属于正常待命，不触发WE采集的10秒无帧错误。所有screencast事件均ACK，接收端只保留最新帧，并限制向每个Codex目标的未完成提交数。
- 初始化失败或选择被取代，关闭候选浏览器、服务与流，旧选择保留；运行中故障使用现有恢复链路。源码新入口不等于所有作者网页功能通过验收。

## 安全边界

作者在不含allow-same-origin的opaque iframe中运行，无Node或preload能力。服务仅绑定127.0.0.1，使用随机项目token、精确Host、字面路径和realpath围栏，只服务项目资源；Range/HEAD复用上游实现。官方客户端只接收JPEG，不执行作者HTML/JS。调试连接使用继承管道，无网络CDP端口；宿主进程结束时管道关闭，专用浏览器退出。

自有wrapper和作者资源使用各自的CSP；Fetch拦截覆盖页面及跨进程iframe，worker禁用HTTP加载。含作者meta CSP的入口暂直接拒绝，避免注入在其策略之前执行；不改写作者策略。下载、摄像头、麦克风等能力禁用。外部HTTP脚本、worker请求和导航的本机第二端口探测均未到达目标服务器；这不是对所有Chromium网络API和恶意内容的完整安全审计。

## 验证与实际边界

9项相关单元/动作检查通过：保存不启动、engine持久化、WE/Chromium版本精确重复匹配、4K不调用WE profile、静态/自定义档位恢复与首帧失败回滚等。面板定向隔离检查通过，保留筛选/按钮间距、引导横栏材质、主题和既有控件行为。

有界真实调试管道检查通过：动画JPEG发生变化、ACK、暂停时进程退出、恢复新进程/新帧、连续状态修改/恢复中停止、10秒以上静态页健康、属性重seed、候选取消、作者CSP拒绝、外部HTTP隔离，以及宿主直接退出后浏览器随之退出。最终fixture首帧约1.36秒，单次测量，不是机器冷盘或所有网页的性能保证。

本机两个真实Web项目已独立加载：Corsair-O-Tron约2.0秒首帧，检查到其实际图案；短样本未观察到内容动画变化。另一个音频可视化项目只有黑帧，存在资源404，不能称为功能通过。音频和完整作者效果仍需各项目核实；原版WE保留后备。
