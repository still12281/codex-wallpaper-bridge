## C3 字体补修

当前 Codex CSP 的 font-src 允许 self/data，不允许 blob；原引擎给 FontFace 的 Blob URL 在真实隐藏沙箱加载失败，同一原始字体字节输入成功。这不是共享字体文件缺失。

依据标准 [FontFace 构造器的二进制输入](https://developer.mozilla.org/en-US/docs/Web/API/FontFace/FontFace)，在本项目加载器内仅对固定 WebWallGL 3.0.0 的唯一匹配片段，把已由上游 sanitizeFontForBrowser 处理的 ge 直接传给 FontFace。安装引擎、CSP、上游 vendor 原件不变；字体登记/释放及无用Blob URL清理仍走原生命周期。未增加网络、本地文件能力或全局Blob/FontFace改写。未来引擎不匹配时原样运行，并报告字体适配未匹配，不能假定升级后继续有效。

实际 Codex 隐藏生成文字场景：内嵌字体1个加载，文字改变像素，当前渲染器和配置字节一致；严格字体CSP的隔离WebGL回归通过。测试字体取本机系统字体，仅在仓库外生成场景中使用，不复制入Git。证据：`../package-c-work/{font-csp-result.json,font-renderer-result.json,font-webgl-result.json}`。共享WE字体后备、动态字体切换、组件仍待完成，不宣称所有工坊字体一致。

同时修正固定分辨率cover裁切时的指针映射：使用iframe实际矩形反算位置，避免将宿主归一化坐标直接当作完整画布坐标；带负偏移/缩放矩形的隔离事件检查通过，实际可见作者鼠标效果仍待验收。
