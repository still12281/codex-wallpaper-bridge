# 壁纸控制面板样式整理

用户指定参考[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)。已读取README、MIT说明及同一版本的[Linear分析](https://github.com/VoltAgent/awesome-design-md/blob/3b605329240ce735b510037cca322f1831fdd7f8/design-md/linear.app/DESIGN.md)、[Raycast分析](https://github.com/VoltAgent/awesome-design-md/blob/3b605329240ce735b510037cca322f1831fdd7f8/design-md/raycast/DESIGN.md)，参考提交为`3b605329240ce735b510037cca322f1831fdd7f8`。这些是网站设计分析，不等同于品牌官方应用规范。本轮采用适合桌面控制面板的层级/间距原则，未复制完整设计文档或品牌字体、图像、标识和脚本。

## 本轮调整

- 面板使用背景、普通表面、抬升表面三层色阶，细边框区分预览、筛选和高级设置；壁纸取色以轻微背景混色保留。明暗模式及手动主题选择保持有效，不改聊天区/壁纸渲染样式。
- 统一36px普通控件、8px控件圆角、10/12px卡片圆角、12/14/16px分组间距；中文正文、标签、说明有清楚的字号/字重层级，使用本地系统字体。
- 每个操作区保留明确的主要动作；批量保存与完成按钮回归次级，删除使用文字语义和危险色，不与应用按钮竞争。原先的预览后确认、单项和批量处理不变。
- 当前壁纸预览、待导入预览、批量区分别分组；筛选栏、卡片名称/模式/导入状态和底部选择栏统一。高级设置改为可折叠分组卡片，不隐藏或删除原操作。
- 保留焦点环、忙碌/禁用、悬停/按下和减少动态效果偏好；仅120ms颜色/边框变化，不新增背景模糊、常驻动画、字体请求、图片或第三方运行库。

## 验证

复用现有隔离Chrome测试，明确清空截图输出环境变量。没有调用截图/录屏接口，也没有生成图像文件。覆盖明暗主题错误提示/下拉文字对比度不低于4.5:1、手动主题、36px控件、主次按钮、无外部字体/背景模糊、键盘焦点、拖动/最大化/八边缩放、150%代表缩放、单项/批量分离、忙碌状态、作者属性及原有引导栏样式。

首次回归仍断言旧主题文字RGB值，因此失败；保留主题覆盖语义、更新为新色阶并继续检查对比度后通过。新增交叠探针最初把折叠details内部仍可读取的缓存矩形当作可见内容，修正为检查实际可见性后通过；未为消除测试错误而删减产品功能。只读上游提交响应一度未提取出元数据，随后从已连接GitHub读取并确认上述提交，不使用未核实版本。
