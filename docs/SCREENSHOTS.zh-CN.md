# GitHub演示图片准备

根目录README以中文为主。当前仓库没有真实聊天截图或演示素材，以下是发布图片的采集要求，不是已完成的截图或可见验收。

| 图片 | 展示内容 | 素材与信息要求 |
|---|---|---|
| 主界面 | 壁纸与聊天/侧栏的融合效果 | 新建空白演示聊天，用自制或获授权壁纸；不出现真实聊天、账号和额度信息 |
| 壁纸库与导入 | 缩略图、已导入筛选、单项/批量操作 | 使用自制测试素材和通用名称；隐藏本机目录与工坊个人收藏 |
| 播放与外观 | 画质、FPS、透明度与作者属性 | 选择功能明确支持的场景；标注模式与必要限制 |
| 可选短动图 | 一次选择、确认应用、切换完成 | 不循环展示无关操作；按真实速度播放，不加速冒充加载性能 |

优先三张清晰截图和一个短动图，无需堆砌近似图片。图片标题和说明使用中文，避免让用户通过代码参数理解产品。图中若为合成演示页面，必须明确标注，不能称为真实Codex效果。

公开图片需要另行加入明确的发布文件白名单；当前隐私检查仍拒绝图片/视频文件，不能为了上传方便全局放开运行素材目录。先人工审查版权、账号、路径、聊天和可识别信息，再更新针对具体图片的允许项。不得把当前真实聊天截图直接当作README演示图。
