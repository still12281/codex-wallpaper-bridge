# E：轮播、恢复与收尾

## 已实现及定向检查

- 轮播复用逻辑壁纸分组，兼容旧 entry ID，允许已保存GPU/原版引用；同一项目不同模式不重复轮播。排除隐藏/当前组；每轮每组最多尝试一次，坏素材跳过，手动选择立即使旧候选过期。
- 自动任务入队和真正执行时均核对选中项/revision，再取得独立ticket；后台等待、导入/手动事务串行。手动“下一张”也使用ticket。保存失败或旧背景恢复失败分别报错并停止，不能冒充坏素材继续，更不能未确认恢复仍说保留成功。
- 目标消失时显式释放WebGL player。原有浏览器断开时宿主/助手退出机制保留；隔离生命周期检查通过，不等同当前Codex正常退出验收。
- 备份/恢复/路径诊断补上 customDisplay 中保存的原播放副本；拒绝缺少其引用文件的备份。隔离往返、遗漏/损坏/覆盖/逃逸检查通过。
- 4项轮播/预设测试、备份往返、既有面板及完整隔离端到端通过。新增实际隔离宿主检查通过GPU下一张、回媒体释放、后台等待、自动候选被后到手动选择取消。未重复全仓库测试。
