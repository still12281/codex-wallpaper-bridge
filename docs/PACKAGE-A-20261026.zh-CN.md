## 设计选择与代表对照

主规范采用 Fluent 的中性色层级、语义危险色和焦点/交互状态。参考 [Fluent 2 色彩规范](https://fluent2.microsoft.design/color) 和 [shadcn 按钮分类](https://ui.shadcn.com/docs/components/base/button)，并核对本地 DSH 的 `styles-settings.js` 与图库结构。仅参考设计，不复制第三方组件源码；保留已有 DSH MIT 署名，不增加 React/Tailwind 或额外运行时。

| 组件 | 原状态 | 当前规范 |
|---|---|---|
| 按钮 | 通用暗色底，危险/主操作视觉相同 | 34px 最小高度、8px 圆角、8px 组内间距；主操作强调色，删除用危险色；标题栏保留桌面式按钮 |
| 字段 | 多处独立色值和边框，checkbox 被全宽输入规则命中 | 成对主题文字/实底、统一边框和焦点环；原生 select/checkbox 与键盘语义保留 |
| 图库 | 大视口中窄面板仍三列；超长标题挤压，sticky 预览遮卡片 | 按容器 3/2/1 列，长标题有界并保留完整可访问名称；预览随内容滚动 |
| 操作组 | 勾选后三个入口等价 | 当前项两项操作 + 一个勾选项批量保存入口 |
| 浮层 | 部分 elevated 变量沿用原主题，玻璃样式只命中未接线标记 | 当前语义浮层配对文字/底色；实际引用栏直接接入；阅读浮层限制透明度下限 |
