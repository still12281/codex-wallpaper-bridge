# Web 路线、大场景首次加载与内存归因

本轮从干净 `42bd3fb` 续接。先读 task_plan 和 C/D/E 实施记录，再核对实际部署：原 36 个 src 模块与仓库一致、9 条库记录、当前媒体背景，现有一体入口不变。旧记录的“34 个运行模块”是当时统计口径，本轮逐文件统计为 36，新增传输模块后为 37。

## Web 路线裁决

通用 Web 项目继续使用已有 **Wallpaper Engine 专用窗口 → WGC → Codex canvas** 路线。`realtime-source.mjs` 已接受 scene/web，复用当前唯一命名的自有窗口、采集和退出清理，不新增服务或常驻监控。本轮没有选择或操作用户 Web 场景，不能宣称具体 Web 项目已通过采集、鼠标或作者属性验收。

GPU Web 仍明确禁用。固定上游的 Web API 需要可导航入口，再 fetch HTML、插入 base/内联 WE shim 并创建 Blob iframe；现有 Scene 字节 source 只有 project/sceneDir/scenePkg。项目字节读取不能直接替代 HTML/CSS/模块/动态资源解析器。既有受当前 CSP 限制的实验在 connect-src 前阻断、Fetch 拦截数为 0；Blob 文档还会继承创建者 CSP，允许 frame 导航并不等于允许其作者脚本。参考 [CSP 文档继承](https://www.w3.org/TR/CSP/#security-inherit-csp)。

因此不再重复 HTTP 嵌入，不伪装官方可信域，不通过一般性 CDP 求值重做通用作者脚本加载器。保留 opaque sandbox、原版后备和当前配置。本轮不把路线判断勾成 C2 功能完成。

## 大场景首次加载根因和修改

样本为工坊 3600630828，场景包 212,117,705 字节。复制当前 Codex meta CSP 的隔离 Chromium 首次就绪约 8.70 秒：51 次 Base64/CDP 传输累计约 6.03 秒，Cache API 写入并投递约 0.65 秒。各分段有重叠，不能简单相加。gzip level 1/3 均只减小约 0.15%，编码另耗约 3.6 秒，未采用。

新增 host-only `reader.localFile()`，沿用 realpath 目录围栏、资源大小/累计预算和源版本复核；通过 CDP [DOM.setFileInputFiles](https://chromedevtools.github.io/devtools-protocol/tot/DOM/#method-setFileInputFiles) 将已验证的单个路径交给 trusted page 的 detached input，再由可取消 FileReader 直接读字节。输入节点不插入 DOM，用后清空文件并释放 remote object。字节沿用既有缓存和 transferable 投递，作者拿不到 File、路径、DOM 或新文件访问能力。没有网络传输、CSP 绕过或官方文件修改。

协议明确缺失/受限时保留原 Base64 后备；取消、读取失败和源变化不走静默重试。异步读取绑定 handle identity，abort 同时调用 FileReader.abort，防止慢盘读取在快切后继续重叠。仅读取期间使用 25ms 取消检查，用后清理，不是常驻监控。

| 对照 | 修改前 | 修改后 | 边界 |
|---|---:|---:|---|
| 复制当前 CSP 的独立 Chromium，大包资源缓存未命中 | 8.70s | 原型 2.03s | 隔离样本，不是当前可见 Codex |
| 当前 Codex/AMD 主窗口隐藏候选，强制跳过资源缓存命中 | 6.92s | 原型 1.34s | 同一原项目，原背景未采用/替换 |
| 最终已部署 FileReader 版本，主/分离页隐藏候选 | — | 1.60s / 1.32s | 字节来源为文件，Base64 传输为 0；配置未写入 |

这里的冷加载是浏览器资源缓存未命中，不是清空 OS 文件缓存或新机器冷盘。隐藏候选首帧就绪也不是点击到物理可见画面的完整延迟。原项目的 WebGL 效果/字体/脚本兼容缺口仍保留，加载更快不能当作效果保真验收；原生 WE 的启动耗时不由这项 GPU 资源传输优化证明。

## 定向验证与部署

8MiB 实际浏览器字节哈希一致；协议缺失后的 Base64 后备字节一致；延迟读取取消约 15.94ms，底层 abort 被调用、旧 handle 不能复活；源版本改变和越界路径拒绝通过。扩充原 reader 围栏单测覆盖 localFile；没有跑无关全仓库测试。

部署只替换四个 src 模块（含一个新模块），外部备份后重载自有宿主。37 个运行模块逐字节一致，主/分离页 ready，9 条库和 settings 字节相同，Codex browser identity、当前背景和一体入口文件一致。宿主重载重新装配当前媒体，不承诺媒体播放位置保持。

私有证据在仓库外 `../switch-work/`：`baseline.json`、`optimized.json`、`file-probe.json`、`transfer-check.json`、`native-cold.json`、`deploy-result.json`、`deployed-verification.json`、`deploy-backup/`。脚本同目录保留；配置、原始素材、浏览器数据、采样和大文件不入 Git。
