# 图片来源

本目录仅保存经过人工核对的 9 张 **v0.4.1** 真实桌面端实拍 PNG（2026-11-26 采集）。完整索引、界面说明、版权范围与发布规则见[桌面端实拍索引](../SCREENSHOTS.zh-CN.md)。

- 范围：仅截取正在运行的 Windows Codex 桌面客户端窗口（`2006×1363`），不含桌面、任务栏或其它应用。
- 背景：空白新对话界面，左侧对话列表收起；控制面板直接按实际打开位置拍摄。
- 第三方壁纸：主图壁纸来自 Steam Workshop [3287715210](https://steamcommunity.com/sharedfiles/filedetails/?id=3287715210)（发光少女 4K动态壁纸）；画廊及轮播列表中显示的条目同属各自权利人，仓库不打包原素材也不追加授权。
- 文件：像素未拼接或涂改，仅做无损 PNG 重新压缩并剥离非必要元数据块（仅保留 `IHDR`、`IDAT`、`IEND`）。
- 发布：仅白名单中的具体文件名与原始字节 SHA-256 可通过发布校验，不接收其它截图、配置、素材或日志。
